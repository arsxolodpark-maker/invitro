# ПРИИЗ v0.7 - UX-проход по аналитике v9

Основа: документ «Описание функциональности Системы регистрации обращений v9» и протокол обсуждения с владельцем продукта.

## Цель
Привести прототип к реальному end-to-end процессу ПРИИЗ: внешний Инициатор + внутренний контур ДКП/Project/Администратор + инженерный контур 1C:ITILIUM + Express.

## Что реализуется
- отдельный внешний сценарий Инициатора;
- активация учетной записи по приглашению и вход;
- ДКП: управление внешними инициаторами;
- Инженер ГСТИ: демонстрационный просмотр обращения как зеркало 1C:ITILIUM, без попытки заменить рабочее место инженера;
- Администратор: пользователи, роли, чаты Express;
- Project: отдельный аналитический view, помеченный как дополнительный внутренний view прототипа;
- статусная модель портала из v9: Новое / В работе / Отложено / Ожидает ответа / Ожидает согласования / Выполнено / Закрыт;
- отображение подтвержденной интеграции с 1C:ITILIUM;
- демонстрация события уведомления в Express;
- self-registration оставляется TBD из-за конфликта требований в v9;
- каталог обращений не расширяется до получения реальной статистики.

## Контрольный сценарий
ДКП создает Инициатора -> Инициатор активирует аккаунт -> создает обращение -> обращение синхронизируется с 1C:ITILIUM -> Инженер ГСТИ отвечает -> статус меняется -> Инициатор видит ответ -> обращение закрывается -> Project видит аналитику.
