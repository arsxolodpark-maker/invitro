# GOVIN-303 · Проверка направления

Публичный DEMO-модуль единого фронта ДКП.

## Что показывает прототип

- явный выбор интеграции: Нетрика / Адыгея / Брегис;
- поиск внешнего направления по штрихкоду;
- состояние «не найдено»;
- карточку направления;
- внешний ID, дату, клиента и исходный технический статус;
- ИНЗ;
- назначенные и доставленные тесты;
- доступные демонстрационные ошибки чекина/доставки;
- дату последней доставки;
- отдельное пользовательское состояние этапа и диагностической проблемы;
- демонстрационный переход «Создать обращение в ПРИИЗ» с предзаполнением только доступных данных GOVIN.

## Безопасность публичной версии

В репозитории не размещаются исходные документы INVITRO, внутренние API-адреса, секреты, реальные медицинские данные, ПДн, промышленная архитектура и закрытые технические материалы.

Все значения в `demoData.ts` вымышлены.

## Границы

Этот модуль является UI-прототипом. Он не подтверждает фактическое наличие или состояние промышленных компонентов GOVIN, Gateway, сервисов интеграций или контракта GOVIN → ПРИИЗ.

Контекст GOVIN → ПРИИЗ является DESIGN-моделью. Поля, которых GOVIN не знает, не выдумываются и остаются на ручное заполнение.

Автоматический поиск сразу по всем интеграциям в текущий MVP не входит.
