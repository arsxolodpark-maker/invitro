# ПРИИЗ INVITRO v0.4 DEMO - пакет передачи Ирине

## Что зафиксировано

Ветка передачи: `handoff/priiz-v0.4-demo`

Эта ветка содержит текущий рабочий код прототипа и отдельный файл с базовым рабочим промтом:

- `handoff/PROMPT_PRIIZ_v0.4.md`
- весь исходный код приложения в `src/`
- конфигурацию Vite / TypeScript / GitHub Pages
- README проекта

Цель ветки - сохранить стабильную контрольную точку, от которой можно сделать независимую копию в другом GitHub-репозитории.

## Технологии

- React
- TypeScript
- Vite
- Tailwind CSS
- localStorage / mock-данные
- GitHub Pages для DEMO

Backend и реальные интеграции INVITRO в этой версии отсутствуют.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-проверка:

```bash

```

## Как Ирине забрать проект в свой GitHub

### Вариант 1 - самый простой: GitHub Import / новый репозиторий

1. Создать новый пустой репозиторий в своём GitHub.
2. Скопировать код из этого репозитория или клонировать его локально.
3. Переключиться на ветку передачи:

```bash
git checkout handoff/priiz-v0.4-demo
```

4. Создать собственную основную ветку из этой точки:

```bash
git checkout -b main-irina
```

5. Подключить свой новый репозиторий как remote и отправить код:

```bash
git remote remove origin
git remote add origin <URL_НОВОГО_РЕПОЗИТОРИЯ>
git push -u origin main-irina
```

После этого ветку можно переименовать в `main` в своём репозитории.

### Вариант 2 - Fork

Если GitHub-политика позволяет, можно сделать Fork исходного репозитория и создать свою рабочую ветку от `handoff/priiz-v0.4-demo`.

Для полностью независимого проекта лучше вариант 1.

## GitHub Pages

В текущем репозитории Vite использует base path `/invitro/`.

Если новый репозиторий Ирины будет называться иначе, например `priiz`, в `vite.config.ts` нужно заменить:

```ts
base: '/invitro/'
```

на:

```ts
base: '/priiz/'
```

или на путь, совпадающий с именем её репозитория.

Workflow публикации лежит в:

`.github/workflows/deploy.yml`

После переноса нужно включить в GitHub:

`Settings -> Pages -> Source -> GitHub Actions`
