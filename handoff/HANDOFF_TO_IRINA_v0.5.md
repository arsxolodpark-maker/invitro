# ПРИИЗ INVITRO v0.5 - передача

Контрольная версия после комментариев Ирины от 18.08.2026.

## Что читать сначала

1. `README.md`
2. `handoff/PROMPT_PRIIZ_v0.5.md`
3. Product Blueprint / PRD / техническую спецификацию из пакета документации
4. `src/`

## Что изменилось относительно v0.4

- роли: Администратор / ДКП / Project / Support;
- убраны Manager и отдельная роль Product;
- аналитика стала разделом Project;
- Architecture & TBD заменен на Базу знаний;
- добавлен Admin DEMO;
- показан единый portal shell ДКП с будущими отдельными модулями;
- зафиксирована целевая синхронизация с Итилиумом;
- крупные hero-баннеры убраны;
- INC-02 остается единственным рабочим demo-flow до получения статистики типов.

## Запуск

```bash
npm install
npm run dev
```

Проверка:

```bash
npm run lint
npm run build
```

## Важно

Не подключать реальные API/ПДн в публичную DEMO-сборку. Source of truth, mapping Итилиума, IAM и источники Базы знаний остаются TBD.

Если проект переносится в другой GitHub-репозиторий, проверить `base` в `vite.config.ts`: он должен соответствовать имени нового репозитория для GitHub Pages.
