# ПРИИЗ INVITRO - UX Prototype v0.5 DEMO

Рабочий UX-прототип модуля «Инциденты / ПРИИЗ» внутри целевого единого портала ДКП.

> Точная расшифровка «ПРИИЗ» пока не подтверждена, поэтому сокращение используется без расшифровки.

## Что изменилось после комментариев Ирины 18.08.2026

- добавлена роль `Администратор` для пользователей и ролей;
- ролевой набор сокращен до `Администратор / ДКП / Project / Support`;
- `Manager` и отдельная роль `Product` удалены;
- аналитика стала разделом `Project`;
- `Архитектура & TBD` удалена из пользовательской навигации;
- добавлена `База знаний` для проектной документации, runbook и инструкций;
- зафиксировано целевое направление синхронизации `ПРИИЗ ↔ Итилиум` без реального API;
- крупные промо-баннеры убраны: интерфейс оформлен как внутренний рабочий инструмент;
- для ДКП показан общий portal shell с будущими отдельными модулями: Инциденты, ОМС/лимиты, Маркетплейс, Покрытие, Платформа;
- каталог инцидентов больше не расширяется гипотезами: рабочий DEMO-flow пока только `INC-02 Не получен результат`.

## Главный продуктовый принцип

ПРИИЗ не заменяет существующую интеграционную платформу или Итилиум. Пользовательский портал собирает контекст и дает ДКП прозрачный статус, а Support должен иметь возможность работать в существующем рабочем контуре без двойного ведения одной заявки.

## Что демонстрирует v0.5

1. Единый portal shell и роль ДКП.
2. Рабочий список инцидентов без рекламного hero-блока.
3. Создание `INC-02` через динамическую форму.
4. Mock pre-check без внешних вызовов.
5. Единая карточка и переписка.
6. DEMO/TBD-блок синхронизации с Итилиумом.
7. Внутреннюю Integration Console только для Support.
8. Project Analytics на `DEMO DATA`.
9. Базу знаний с DEMO-поиском.
10. DEMO-администрирование пользователей и ролей.

## Что намеренно не реализовано

- реальные API Итилиума/INVITRO;
- production IAM/SSO/RBAC;
- реальные медицинские или персональные данные;
- конкретные дополнительные типы инцидентов без статистики;
- реальный AI/RAG для базы знаний;
- полноценные модули ОМС, Маркетплейс, Покрытие и Платформа внутри ПРИИЗ.

## Безопасность DEMO

Все клиенты, ИНЗ, тикеты, метрики и технические результаты в репозитории являются демонстрационными. Реальные внутренние URL, секреты и персональные/медицинские данные не используются.
